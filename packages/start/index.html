Everything stays on this computer. The model is illustrative and has not been validated for regulatory use.

Start from your own data

Choose one file with a balance sheet per institution, and optionally one with who has lent to whom. Konjugate checks them, tells you exactly what it finds wrong, and builds the model.

Choose a scenario

Each scenario runs the same model twice: once as it is, and once with a shock from day 5, so you can see exactly what the shock changes.
