Getting started

Five minutes from a spreadsheet to a stress-test comparison.

1. Load your data

On Your data, choose your institutions file (one balance sheet per institution) and, if you have it, your exposures file (who has lent to whom). Or press Use the sample data to try the tool with eight fictional banks. Konjugate checks the files and tells you exactly which row has a problem. Nothing leaves your computer.

2. Choose a scenario

Each scenario runs your model twice: once as it is, and once with a shock starting on day 5. For a run on one institution, you choose which one; it starts with your largest. The window lists exactly what the scenario changes.

3. Read the comparison

The headline says how many institutions fail, which fails first and when, and how much equity is lost, next to the same figures with no shock. The chart shows the most affected institutions' equity as a share of where it started: a dashed line is the baseline, a solid line is the scenario, and a line below zero is an insolvent institution. The table lists every institution.

4. Inspect, save, repeat

Open in Konjugate shows the same two runs in the main window as a baseline and a forked branch, where every equation and parameter can be inspected and changed. Export results writes the full time series, a summary, the model, and a run manifest recording exactly what produced them, ready to attach to a report or compare with next quarter's run.

The model is illustrative. It has not been validated against real data or reviewed by a practitioner, and it should not be used for regulatory reporting. See Assumptions and limits.
